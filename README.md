# Dodge Game 🎮

My first Pygame project — a simple 2D dodge game.

## About

Dodge the falling enemies and survive for as long as possible. The longer you survive, the faster and more difficult the game becomes.

## Features

- Player movement
- Two different enemies
- Enemy movement patterns
- Collision detection
- Score and high score system
- Increasing difficulty
- Start screen
- Game Over screen
- Restart system
- Custom sprites and background

## Controls

- **Left Arrow** — Move left
- **Right Arrow** — Move right
- **Space** — Start the game
- **R** — Restart after Game Over

## Built With

- Python
- Pygame

## Project

This is my first Pygame game project, built while learning Python and game development.
